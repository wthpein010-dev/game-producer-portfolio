# 对对碰公开范围

2026-11-18，按用户本轮要求更新：职业介绍仅保留任职、个人职责与通用工作方法。游戏配图使用用户确认的六张玩法截图及从用户已打开的微信正式小游戏中新截取的七张系统截图；恢复用户之前提供的 60 秒连续操作节选。素材清单及哈希见 `src/sheep-playtest.mjs`。

项目原始文档、内部截图、未上线方案、测试与分析结果及旧效果稿不进入当前发布树。视频仅含游戏操作节选，无聊天、广告、账号及通知。系统截图裁取实际界面，对运行标识及用户 ID 使用不透明遮盖，原始捕获留在被忽略的 `artifacts/`。不公开包含其他玩家头像的主页与榜单。相关原型与内部工具入口继续从简历目录排除。

此修改不重写 Git 历史，不更改外部 Hub 仓库，也不把用户对截图来源的确认视为公司的全面素材授权。后续素材仍需核对权利与公开范围。

验证：指定 CI 套件、`tests/sheep-privacy.test.mjs`、`tests/sheep-privacy-smoke.mjs`。浏览器验证使用无界面模式，报告保留在被忽略的 `artifacts/`。
