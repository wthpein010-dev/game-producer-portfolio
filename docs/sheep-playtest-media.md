## 维护与验收

`scripts/prepare-sheep-playtest.ps1 -Ffmpeg <本机ffmpeg路径>` 使用源线程外部原件生成公开节选；换电脑不能假定原件仍存在。原件路径仅供来源交接，不作为公共入口。

新增 `tests/sheep-playtest.test.mjs` 纳入指定 CI 套件。专项浏览器回归 `tests/sheep-playtest-smoke.mjs` 核对四种视口、两段视频实际播放与尺寸／时长、视频跳转、折叠状态、图像解码、原图弹窗、无横溢及无脚本阅读。既有早期图文回归先显式展开历史稿再截图。

本地预览原先未支持 HTTP Range，浏览器虽能播放却无法跳转进度（seekable 为 0）；本轮为预览服务器补充单段字节范围、尾部范围、HEAD、416 及 video/mp4 MIME，保留原有公共路径约束，以 `tests/media-server.test.mjs` 验证。不将原先仅触发 seeked 事件误报为成功跳转；专项检查跳转后实际 currentTime。

发布前本地结果：74 项指定静态与服务器测试通过；四种宽度下两段视频实际播放、1/15/35/58 秒跳转、图片解码、折叠、原图关闭及无脚本模式通过。既有对对碰图文与首页工具目录回归通过。完整原片、聊天分享画面、通知和广告均不在公开资源中。
