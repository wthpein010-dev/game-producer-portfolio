# 作品集图片加载优化

用户目标：保留现有GitHub展示入口，使图片加载更快；用户明确授权按助手判断直接完成并给出网页。

沿用已确认的内容站设计、全部履历与截图来源。采用构建时生成响应式WebP预览，原图字节与原图链接保留；不新增付费资源或域名服务。曾考虑北京3Mbps直接供图、域名+CDN，前者带宽与HTTPS/公网条件不适合本轮直接加速，后者需要用户尚未提供的域名及备案。选择不增加服务成本的图片减重，这是本轮实施判断。

生成480/960/1440/1920宽度候选，不上采样，并纳入不超过1920的原宽候选。PNG使用无损WebP保护图文，其他截图采用高质量编码；已足够小的图可继续使用原文件。预览使用srcset/sizes，保留固有宽高、alt、懒加载与原图链接。原尺寸details仍使用原图+原生lazy，只有展开才加载；点击灯箱加载原图，关闭脚本也可看预览并打开原图。

响应式处理在共享HTML构建阶段完成，无运行时清单请求；三张动态项目封面改为同结构静态输出。图示SVG、颜色字体与布局不变。原图、公开说明和许可保留，内部记录不进入发布目录。

验证覆盖：生成确定性/原图SHA/尺寸与透明度、纯函数HTML转换、全站构建/现有43项契约、移动桌面浏览器选图/原图按需/无JS/键盘/错误状态、代表图清晰度对比、发布线上逐文件检查。发布至原main且保留真实远端父链；服务器副本同步为新版本目录，不公开未备案端口。
