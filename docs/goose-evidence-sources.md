# 百变汪星人资料来源

2026-10-08 由用户确认 Goose 资料归属《百变汪星人》，Train 资料归属《谁是火车王》。2026-11-20 复核 Goose 的 `策划/各功能文档` 和 `美术/UI` 中与本页直接相关的文件。

## 范围与归属

目录中存在《百变汪星人》小游戏提审-180809，功能文档明确狗场、狗窝和狗的养成经营，支持项目关联。提审登记、企业信息、账号、程序和完整原件不公开。立项案原名《超级铲屎官》，称基于《疯狂鹅场》后续开发，保留历史名称，不据目录推定完整更名时间线。

本轮计算的立项案 SHA256 与此前核验记录一致，署名和图文出处沿用该次核验。立项案转换后的页眉为“系统文档 策划：吴天昊”。封面日期为 2018/6/14，文件名记录 20180629 版本。复核了主界面、背包、好友、成就和图鉴功能案正文与内嵌界面图。独立功能案用来核对项目规则，界面稿归属团队美术。

立项案写在场／库存分页。独立背包案正文写狗窝按格存放，内嵌图和历史美术稿显示狗舍／场景分页。主界面功能案把图鉴归入折叠菜单，`test/MainUI2.png` 将图鉴显示为底部按钮。正文与图注分别对应各自的历史材料。
