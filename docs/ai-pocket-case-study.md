## 已核对事实

- 目标：降低非技术用户在办公、电商、写作及视频任务中选择工具、准备环境和学习操作的门槛。
- 信息架构：六类任务、十六个子类、五十四张任务卡；采用任务用途、图示与官方工具入口组织操作。
- 本地办公：CSV 清理、去重、分类计数与结果预览；公开结果使用明确的教学样例。
- 本地视频：集成 ComfyUI 与 Wan2.1 T2V 1.3B，运行时和模型随交付包提供，首次使用自动准备环境。本机已通过助手生成约五秒、608×352 的无原生音频样片。
- 交付资料：二十四页使用说明 PPT、中文配音操作教程、练习资料及 FAQ；用户、甲方与客服资料分开。
- 版本阶段：免登录 Windows 本机验证版本，本机验证完成。当前版本不注册、不上传账号。

## 实施与验收计划

1. 复用既有首页案例与详情模板，添加独立内容模块与路由，保留三精选及折叠行为。
2. 先写定向内容、路由与公开边界测试，再加入模块、样式与六张图片。
3. 构建所有生成页，运行当前 CI 明确列出的测试及新增专项，不运行无过滤套件。
4. 后台 Chromium 检查桌面、平板、手机、图片解码、原图放大、Escape 关闭、返回链接、减少动效及关闭脚本阅读。
5. 审查差异和公开资料后正常推送，等待同一提交的 CI 与 Pages 完成，再从公网核对文字、图片字节与交互。详细报告保留本地 `artifacts/ai-pocket/`，不作为公众资料发布。
