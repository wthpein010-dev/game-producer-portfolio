# 字体来源与使用

Producer Display 是得意黑 Smiley Sans v2.0.1 的网页子集，使用本站公开页面的字符制作，移除 hinting，并改用独立字体族与 PostScript 名称。仅用于展示标题；原版权与许可证记录保留。原始来源与发行：[atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1)。许可见 `SmileySans-OFL.txt`。

IBM Plex Sans Regular / Medium 保持官方文件不变，用于拉丁文字和数字。来源：[IBM/plex](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/woff2)。许可见 `IBMPlexSans-OFL.txt`。

字体由本站自托管，页面不调用第三方字体服务。新增标题若超出子集范围，会使用可读的系统中文字体回退；内容更新时可重新制作子集。
