# 字体来源与使用

Producer Display 是旧版标题所用的得意黑 Smiley Sans v2.0.1 网页子集。文件保留供旧版样式读取，新版页面已改用系统直立无衬线字体。原始来源与发行：[atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1)。许可见 `SmileySans-OFL.txt`。

IBM Plex Sans Regular / Medium 保持官方文件不变，用于拉丁文字和数字。来源：[IBM/plex](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/woff2)。许可见 `IBMPlexSans-OFL.txt`。

页面使用系统中文字体及本站自托管的辅助字体。
